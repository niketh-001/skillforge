# SkillForge Backend API

Collaborative Learning & Mentorship Platform - Backend

## Tech Stack

- Node.js + Express.js
- MongoDB + Mongoose
- JWT Authentication
- Socket.IO (Real-time)
- Cloudinary (Image storage)
- Winston (Logging)
- Joi (Validation)
- Swagger (API docs)

## Getting Started

### Prerequisites
- Node.js 18+
- MongoDB (local or Atlas)
- Cloudinary account
